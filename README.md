# WARZONE: LAST SURVIVOR (3D Browser Battle Royale)

A complete, AAA-style 3D Battle Royale Browser Shooting Prototype inspired by modern tactical shooters. Built using original graphics primitives, WebGL (Three.js), and procedural Web Audio API sounds.

---

## 🎮 Core Gameplay Mechanics
- **Parachute Insertion State**: Control dive angle and steer aerial landing position.
- **Weapon Loot Scavenging**: Ground loot featuring Assault Rifles, Submachine Guns, Shotguns, and Snipers.
- **Shrinking Safe Zone System**: Circle shrinks over time, causing damage to outside operators.
- **AI Operative Combat**: 29 active autonomous AI agents patrolling, acquiring targets, and firing.
- **HUD & Radar System**: Tactical mini-map, operational kill feed, dynamic hit markers, and ammo counter.
- **LocalStorage Data Integration**: Track lifetime operational stats, including victories, kills, and K/D ratios.

---

## 🕹️ Game Controls
- **W / A / S / D**: Ground Movement / Steering Parachute
- **SHIFT**: Tactical Sprint Acceleration
- **MOUSE**: Direction Look / Aim Perspective
- **LEFT CLICK**: Primary Weapon Discharge
- **E**: Collect Nearby Weapon Loot
- **1 / 2**: Swap Primary and Secondary Inventory Slots
- **R**: Tactical Magazine Reload
- **ESC / P**: Pause Match Menu

---

## 🛠️ Built With
- **Three.js (r128)**: 3D Scene Management, Lighting, Shadow Projection, Matrix Computations
- **Vanilla JavaScript (ES6+)**: Game Loops, AI Behavior Engines, Physics Detection
- **Web Audio API**: Synthetic Frequency Audio Wave Synthesis (Gunshots, Hits, Loot Pickups)
- **HTML5/CSS3**: Custom Tactical User Interface and Dynamic Overlay Systems

---

## 🚀 Quickstart Guide
1. Download or save `index.html`.
2. Open `index.html` directly inside any browser (Chrome, Edge, Firefox, or Safari).
3. Click **DEPLOY TO MATCH** on the main screen to begin.
